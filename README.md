# MyOS

Графическая ОС с собственным ядром (32-бит, protected mode, multiboot),
рабочим столом с поддержкой мыши и курсоров в формате `.cur` (как в Windows).

## Структура проекта

```
MyOS/
├── SYSTEM/
│   ├── kernel/          ядро: память, прерывания, VESA, PS/2 мышь/клавиатура,
│   │                    FAT32 (с in-memory backend), собственные декодеры
│   │                    PNG/ICO/CUR, минимальный INI-парсер
│   ├── desktop/         графическая оболочка: compositor, оконный менеджер,
│   │                    панель задач + меню Пуск, реестр приложений,
│   │                    сохранение расположения иконок (desktop.ini)
│   └── res/
│       ├── cursors/      default.cur — курсор по умолчанию
│       ├── omys.ico      иконка кнопки "Пуск"
│       └── backgrounds/  фон рабочего стола (background_1.png)
├── BOOT/
│   └── grub/grub.cfg    конфиг GRUB: загружает ядро + диск как multiboot-модуль
├── APPS/                встроенные приложения (каждое — своя папка с .png-иконкой)
│   ├── cmd/              командная строка
│   ├── explorer/         проводник
│   └── paint/            графический редактор
└── Makefile             сборка всего проекта + упаковка в единый ISO
```
